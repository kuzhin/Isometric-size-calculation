Расчёт длины трубопровода по векторной изометрии (PDF)


Цель прототипа

Для PDF-изометрии:
1. Найти размеры трассы, включая ответвления.
2. Извлечь размеры и их координаты.
3. Учесть взаимосвязи и вложенность размеров (родитель → внутренний размер).
4. Автоматически выбрать размеры для расчёта.
5. Выполнить расчёт общей длины.
6. Отметить выбранные размеры прямоугольниками на исходном PDF.
7. Выдать список, постраничную сводку и итог.


Важное решение

PDF является векторным, поэтому OCR в этой версии не используется в коде питона, однако будет использоваться на следующем этапе с использованием ИИ.
PyMuPDF читает текстовые объекты непосредственно из PDF вместе с их областью.

На одном листе могут одновременно присутствовать:
- `2450` — общий вертикальный размер;
- `550` — внутренний размер внутри этого же участка.

Также скрипт автоматически отбрасывает:
- `4116` — номер/значение прибора (LT);
- `11550`, `9100`, `8843`, `8373` — отметки Z+;
- `50` — DN50 (диаметр, не длина).
