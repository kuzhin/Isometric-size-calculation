# Проект: расчёт длины трубопровода по векторной изометрии

## Цель прототипа

Для PDF-изометрии:

1. Найти размеры трассы, включая ответвления.
2. Извлечь размеры и их координаты.
3. Учитывать взаимосвязи/вложенность размеров.
4. Выбрать размеры для расчёта.
5. Выполнить расчёт.
6. Отметить выбранные размеры прямоугольниками на исходном PDF.
7. Выдать список и итог.

## Важное решение

PDF является векторным, поэтому OCR в этой версии НЕ используется.
PyMuPDF читает текстовые объекты непосредственно из PDF вместе с bbox.

## Почему нельзя просто сложить все числа

На этом листе есть, например:

- 2450 — общий вертикальный размер;
- 550 — внутренний размер внутри этого участка.

Если сложить оба, получится двойной учёт.

Также:
- 4116 — номер/значение прибора LT;
- 11550, 9100, 8843, 8373 — отметки Z+;
- 50 — DN50.

Поэтому прототип хранит выбранные размеры отдельно от исключённых.

## Установка Windows

```powershell
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск

```powershell
python pipeline_dimensions.py "02_Изометрии_10_листов-10.pdf" --outdir result
```

В `result` появятся:

- `marked_route_dimensions.pdf`
- `selected_dimensions.csv`
- `analysis_report.json`
