Ты — инженер-трубопроводчик и эксперт по изометрическим чертежам (isometric drawings). 
Твоя задача — извлечь из чертежа ВСЕ данные для расчета длины трубопроводной трассы.

Отлично, теперь, давай сделаем проект по приведенному документу PDF (не скан) и заданному ТЗ: 
1. Найти все размеры трассы, включая ответвления. 
2. Извлечь из PDF все размеры и их геометрическую информацию. 
3. Определить взаимосвязи между размерами и классифицировать их. 
4. Выбрать размеры, соответствующие поставленной задаче. 
5. Выполнить необходимый расчёт над выбранными размерами. 
6. Отметить выбранные размеры на исходном PDF прямоугольниками. 
7. Выдать результат расчёта + список использованных размеров. 
Используй python для языка программирования


ЧТО НУЖНО ИЗВЛЕЧЬ:
1. Координаты всех узлов (точек) с маркерами: X, Y, Z в миллиметрах
2. Диаметры труб (DN) для каждого участка
3. Связи между узлами: какие точки соединены трубой (последовательность)
4. Размеры участков (числа на выносных линиях), если они есть
5. Названия подключений (например, "ПОДКЛЮЧЕНИЕ TK-205/I4")

ФОРМАТ ВЫВОДА (СТРОГО JSON):
{
  "sheet_info": {
    "sheet_number": <номер листа>,
    "drawing_number": "<номер чертежа>",
    "connection_name": "<название подключения>"
  },
  "nodes": [
    {
      "id": <номер узла>,
      "marker": "<маркер из < >>",
      "x": <координата X>,
      "y": <координата Y>,
      "z": <координата Z>
    }
  ],
  "segments": [
    {
      "from_node": <id начального узла>,
      "to_node": <id конечного узла>,
      "diameter": "<DNXX>",
      "explicit_length": <размер с чертежа, если есть, иначе null>
    }
  ],
  "metadata": {
    "total_dn_types": ["<список уникальных диаметров>"],
    "notes": "<дополнительная информация>"
  }
}

ПРАВИЛА:
- Если координата не указана явно, но узел связан с предыдущим, используй координаты предыдущего узла для недостающих осей
- Диаметр трубы определяется по ближайшей подписи "DN XX" или "D N X X"
- Связи между узлами определяй по визуальным линиям на чертеже (трубы идут от узла к узлу)
- Если видишь число на выносной линии (например, "1383"), это длина участка в мм — запиши в explicit_length
- Игнорируй справочную информацию (СМ. 4137_14-...) — это ссылки на другие чертежи
